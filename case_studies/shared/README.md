# Shared λ-calculus definitions

Shared higher-order abstract syntax (HOAS) and reduction relations for the [affine](../affine_lambda/README.md) and [linear](../linear_lambda/README.md) λ-calculus studies. The signatures provide [lambda abstraction, application, bang and let-bang terms](lambda_tm.bel), with [linear function and exponential types](lambda_tp.bel).

Separate files define single-step and multi-step reduction, both [with](lambda_dyn.bel) and [without](lambda_dyn_weak.bel) reduction under binders. Typing rules and meta-theorems belong to the individual case studies.
